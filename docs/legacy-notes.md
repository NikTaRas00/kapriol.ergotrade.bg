## Project Overview
Premium **landing site for kapriol.bg** — Kapriol workwear/footwear/PPE, distributed exclusively in Bulgaria by **ergotrade.bg**. Light "concrete / premium industrial" aesthetic (cool neutral off-white, near-black ink, brand-red accent — chosen over dark because the trade/PPE audience reads a bright surface as more credible and it's more legible on a phone outdoors). Multi-page static site: scroll-scrubbed video hero + About + scroll-driven Best Sellers showcase on the landing page, plus separate Products, Product-detail, and Contact pages.

- **Plain static HTML + CSS + vanilla JS. No framework, no build, no npm.** One PHP file (`send-mail.php`) for the contact form only.
- **Pages:** `index.html` (hero + about + best-sellers), `products.html` (catalog), `product.html` (single detail page, data-driven via `?p=<slug>`), `contact.html` (form). All share `assets/css/style.css` + `assets/js/main.js`.
- **`main.js` is one shared IIFE** — every `init()` step is guarded (`renderCatalog`, `renderProduct`, `setupForm`, `setupBestSellers`, `setupHero` no-op if their root element is absent), so one JS file serves all pages with no per-page branching.
- **Data:** `COPY` / `BEST` / `CATEGORIES` live at the top of `main.js`. **The 334-product catalog is NOT inline — it's loaded at runtime from `assets/data/products.json`** (flat array; each item: `category`, `slug`, `name`, `img`, `description`, `features[]`, `overview[]`, plus richer fields `articleCodes`/`sizes`/`colors`/`material`/`standards`/`certifications`…). `main.js` starts with `PRODUCTS = []` and `loadProducts()` fetches the JSON once, then runs `renderCatalog()` + `renderProduct()` (and re-observes the new `.reveal` cards). Throttled at 150ms with `Date.now()`, deliberately not rAF. The URL never changed, so every browser that had seen the first deploy kept serving the old CSS from the 1-year immutable cache — the live Docs page rendered completely unstyled (one giant tile per line) while the server had the correct file all along. **A version string is spent the moment it is deployed; the next edit needs a new one.** Symptom to recognise: the server's copy of the asset contains the new rules (`curl <url> | grep`) but the browser doesn't apply them.
